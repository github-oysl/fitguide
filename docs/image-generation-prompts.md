# FitGuide 动作教学图片素材规范（v2）

执行顺序、验收门槛、次数与恢复策略以 [自动流程](image-generation-workflow.md) 为准；可复制文本见 [提示词模板](equipment-review/action-prompts/_TEMPLATE.md)。旧版“所有图禁止文字/箭头”和“起始图先生成”已经废止。

## 统一视觉

- 写实教学摄影；默认亚洲成年男性，墨绿无大 Logo 运动服，真实自然体型。
- 单张 1:1。完整展示动作所需全身、手脚和关键器械；目标四边约 8% 空间，底部 12% 留给口令/控制，不放接触点。肌群图按解剖范围合理裁切。
- 干净浅灰或柔和中性背景，柔光，器械原有结构与颜色优先，不把红座改成品牌配色。
- 人与器械朝向正确优先于正脸。按动作选择最能说明关节和支撑的机位，不强制全部侧前45度。
- 同组人物、服装、机型、工位、附件、光照和镜头固定；为错误姿势扩大取景时记录变化并复核对比。

## 单独图片的教学语言

| 图片 | 图内指导 |
|---|---|
| 空机 | 不加人物、箭头、肌肉或文案；完整识别真实工位 |
| 起始/结束 | 小型阶段标签、一句可读口令 |
| 发力讲解 | 小标签、1–2条方向明确的绿色箭头、必要接触提示、一句口令 |
| 错误示例 | 可见的单一错误姿势 + 红叉/红圈/轨迹 + 错误名与纠正口令 |
| 主要肌群 | 独立解剖定位、高亮主肌、名称和简短作用说明 |

图内短文逐字校验，保持可编辑文字副本。较长技术说明、训练剂量、呼吸等按需放在详情页独立模块，不打包成大海报。发力方向直接可见是要求；不以“以后HTML补”替代本轮教学图。将来若采用 HTML/SVG 叠层，需交付同等清晰的合成效果并校验。

## 详情页契约（待后续接入）

顺序：动作名和一句口令 → 矮工位识别卡（左图右字）→ 正确动作/错误对比/视频标签 → 当前类型图片 → 主要肌群及动作要点。

工位图虽然方形源文件，容器可以矮，使用完整显示而不是裁关键结构。切换错误/视频时工位上下文保留。正确图按起始、发力、结束展示；生成顺序先发力与展示顺序不同。左右滑动只在当前类型内。视频可缺省，图组承担主要教学。

动作库封面、工位识别图和带指导的发力图各有用途，不强制复用同一资产。主要肌群图可在正确图组下方独立呈现。当前任务只交付规范与模板，不代表这些页面结构已上线。
