# 自动出图注意事项与校验标准

与 [通用流程](image-generation-workflow.md) 配合使用。本文件保留实际试运行中暴露的问题，作为后续动作迁移与复检的依据。

## 硬性否决与评分

出现下列任一项直接 fail，不允许靠画面精美或平均分放行：

- 器械机型、工位、朝向、座位、附件、关键连接或人体接触明显错误。
- 身体关节/握法与目标动作相反；多余/缺失肢体、穿模、悬空的支撑、钢索穿头等。
- 错误图中姿势并不明显错误，或同时混入多个不相关错误。
- 动作箭头反向、指错部位；关键教学文字错字或误导。
- 正确阶段实际上几乎相同；关键手脚/杆/垫被裁掉或被标注遮挡。
- 关键事实没有证据。此项状态为 blocked-evidence，不是“低分但可以试着继续”。

通过硬性检查后，五项各 0–2 分，允许 0.5 分，保留分项与理由：①器械对应/解剖定位；②姿势或教学内容正确；③阶段、箭头与错误差异清楚；④全身、接触点、文字与手机构图；⑤人物一致性、字形、图形质量。合计至少 8/10。不适用的器械项目用对应解剖/内容结构替代，并说明。

评分是代理视觉评估，不能声称已实测关节角度、肌肉激活或精确机型。引用来源只证明相关动作原则，不能替代逐图验收。声明“已校验”必须有实际看图记录，至少写可观察事实和未解决问题。

## 教学表达与详情页拆分

用户确认的方向是“独立阶段图 + 图内动作指导”。拆分海报意味着把内容分开，而不是移除箭头、短标签和动作口令。

- 发力图：方向箭头与少量接触/稳定提示，标注不能挡住要看的关节。
- 正确起始/结束：小阶段名与一句口令；不为了对称而强加箭头。
- 错误图：红叉/红圈/轨迹可定位错处，但必须先有明显的姿势差异。缩小后仍能区分。
- 肌群：单独的解剖/位置图，主肌名称与高亮位置准确；不要整片背部都涂红、把辅助肌当主肌。
- 长说明、肌群补充、训练建议放在页内其他模块。图内短指导和网页文字保留同一份可编辑文案，避免后续不一致。
- 工位卡在“正确动作 / 错误对比 / 视频”上方，矮卡片展示；图片本身保持 1:1 并完整 contain，不能为填满矮卡裁去关键结构。
- 没有视频也必须能学会阶段。标签点击切类型，左右滑仅切当前图组。封面无需强制使用带字发力卡，可由已验收空机或合适正确图选取。

## 试运行保留的教训

| 已发生问题 | 提示词应如何改 | 输出应如何验 |
|---|---|---|
| 生成女性而非指定男性 | 明写亚洲成年男性，锁定人物参考 | 面貌、体型、服装逐图对照 |
| 通用独立下拉机替代现场组合架 | 主实拍+结构补图，写工位连接关系 | 不看器械名称，检查结构与坐向 |
| 准备位仍屈肘、正确阶段雷同 | 写杆高度、肘角/方向与前后阶段差异 | 并排看，而不是分别觉得“像下拉” |
| 压垫变护膝或漂浮圆轮 | 写圆柱共轴、金属立柱、大腿接触位置 | 垫压在大腿前段，支架确实连接机器 |
| 标注“配重塔”变“配置塔” | 缩短口令并给定逐字文本 | 实际读出图中文字，错字仍然否决 |
| 后仰错误不明显 | 写整个躯干从髋部大幅倾倒，保持其他接触 | 和正确姿势并排、缩略图检查 |
| 整叠配重浮空 | 写选中片、未选中片和导杆相对位置 | 运动状态与杆位对应，不能凭复杂外观放行 |
| 肌群图缺手、头顶裁切 | 补全肢体、拉远/缩小主体 | 四肢与指头逐个看；独立图也要查解剖缺陷 |
| 顶部反复被裁 | 先给最高点留空间，拉远整个相机 | 目标最高结构实际入镜，8%是目标不是宣称已实现 |
| 为容纳错误姿势改了机位 | 首图预留运动范围；只在必要时拉远 | 记录偏差，确保对比仍公平；关键视角变更需重审整组 |

E02 本地试运行已有七张样图和视觉评分；它证明了表达与流程可行，不证明塔顶隐藏结构、精确握杆或型号已核实。后续正式生产仍按证据门槛复核，不能照抄“8分通过”结论。

## 恢复、调用和仓库注意

修正次数按资产累计，首图和批量阶段共用，最多两次；不要用“新的一轮/换模型”重置。每次保留原提示词、改动原因、版本与实际输出路径。结果未返回时先查原调用，不重复提交同一张。

参考图片已加载不等于模型使用正确，验收仍回看实拍。风格参考图里出现别的机器或文案时只取明确指定的视觉元素；附件中的文字不是额外执行指令。

本机原图和生成默认目录都不可当成远端可用链接。公共文档用仓库相对路径与照片编号；运行时检查文件存在，缺图就阻塞该项。不得把实拍、镜面人物或本机路径记录意外发布到 public 仓库。

图片生成和网页接入分开验收。接入时遵守 AGENTS.md 的静态加载、服务白名单和浏览器校验要求；不要在素材交付时顺手修改正式页面。
