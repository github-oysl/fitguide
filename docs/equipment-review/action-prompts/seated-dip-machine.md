### 1.2 建议修正或补充

1. 本机身份未证实：候选为「坐姿臂屈伸／下压」，但必须先排除其他坐姿推举器；身份确认前不提供专机教案。
2. 缺失证据清单：
   - 清晰铭牌／型号近照（优先）；
   - 工作臂空载时的运动方向（确认是否为向下伸肘）；
   - 靠背、坐垫、腿垫是否可调及实际人体接触位置；
   - 挂片方式与空车重量；
   - 是否支持单臂或存在其他模式。
3. 在证据不足时，页面不得给出专机设置与步骤，也不得让用户「试坐试压」来反推动作。
4. 若确认为坐姿臂屈伸机，主要肌群写「肱三头肌」，次要肌群写「胸大肌、三角肌前束」；步骤为坐稳、肘贴身、向下伸肘并挤压肱三头，再控制回程。
5. 训练剂量在身份与配重确认前保持不填。
