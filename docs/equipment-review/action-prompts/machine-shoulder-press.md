## 一、核对结论

### 1.1 逐项核对

| 核对项 | 现有内容（摘要） | 结论 | 说明 / 依据 |
|---|---|---|---|
| 主要肌群 | 三角肌前束、中束 · 肩部 | ✅ 正确 | 来源以三角肌前束为主要发力肌，中束在中段参与明显 |
| 次要肌群 | 肱三头肌辅助 | ⚠️ 建议修正 | 来源还列斜方肌上束稳定、胸大肌上部参与，建议补齐 |
| 器械设置 | 推肩机＋靠背；调座椅使把手在耳朵到肩部附近 | ❓ 待器械确认 | 座椅方向合理，但 E15/E21 子型未定；靠背角度、把手高度与握法需现场核对 |
| 动作步骤 | 脚踏稳、臀部靠垫、向上推、控制下降不强迫肩部下放过深 | ✅ 正确 | 与来源「上背贴垫、核心收紧、推到接近伸直不锁死、受控下降」一致 |
| 常见错误 | 需要大幅拱腰才能推起，则重量或座椅不合适 | ✅ 正确，可补充 | 来源另列耸肩、头前伸、半程、借惯性猛顶 |
| 训练剂量 | 2–3 组 × 8–12 次 | ✅ 合理 | 与来源增肌 8–12 次建议一致 |

### 1.2 建议修正或补充

1. 次要肌群改为：「肱三头肌辅助，斜方肌上束与胸大肌上部参与、核心稳定」。
2. 器械设置标注为「通用机型示意，现场需核对靠背角度、把手高度与握法（正握或中立握）」。
3. 常见错误补充：「耸肩」「头前伸」「只做半程」「借惯性猛顶」。
4. 下放深度：可下放至肘部约与肩同高；不必强求更深，以肩部舒适为限，避免在肩后过深牵拉。
