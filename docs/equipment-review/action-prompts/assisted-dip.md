# 辅助双杠臂屈伸 · ASSISTED DIP

- 动作 ID：`assisted-dip`（建议新增）
- 对应实拍器械：E11 辅助引体／双杠臂屈伸机（配重表示辅助，照片 29）
- 适配状态：可直接教学（功能已确认；承托件与进入方法需现场核对）
- 核对日期：2026-09-10
- 现有数据：建议新增
- 重量语义：配重数值越大＝辅助越大＝越省力，**不等于更难**；进阶方向是逐步**减小**配重

### 1.2 建议修正或补充

因本动作属于建议新增，以下为拟定并需现场核对的字段值：

1. **重量语义**必须在动作说明中突出：「配重越大＝辅助越大＝越省力，不等于更难；能标准完成目标次数后应逐步减小配重，过渡到自重臂屈伸」。
2. 器械设置：「先在配重片选好辅助重量，双手握双杠平行把手，膝跪/脚踏承托件；手臂伸直、肩胛下沉起始」。
3. 动作步骤：「屈肘下降至上臂约与地面平行即止；略前倾更偏胸，躯干更直立更偏肱三头；掌根发力推回起始，不锁死肘」。
4. 现场核对项：承托件形式、把手间距与握法、进入/退出顺序、配重辅助传动比。
5. 下放深度以「上臂约与地面平行」为限，不超过该深度，以免肩关节过度受压。
