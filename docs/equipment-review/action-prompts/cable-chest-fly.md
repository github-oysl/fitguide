### 1.2 建议修正或补充

1. 次要肌群改写为：「三角肌前束为主要协同肌，喙肱肌与肩袖等参与稳定」。
2. 器械设置补充：「滑轮高度通常设在肩部附近或略高，可按需调整；顶端双手在胸前靠拢时，钢索方向应与手臂方向基本一致，否则张力会偏向背阔肌或三角肌前束」。
3. 动作步骤补充顶端提示：「想着把双肘在胸前夹拢，顶端可让手臂逐渐伸直，而不是一直屈肘把重量推出去」。
4. 常见错误补充：「耸肩、肩部前引代偿」「用髋部或上身摆动制造惯性」「重量过大导致失形」。

### 1.3 来源

- [StrengthLog · How to Do Standing Cable Chest Fly](https://www.strengthlog.com/standing-cable-chest-fly/) — 访问 2026-09-10 — 支持：胸部为主动肌、三角肌前束为次要肌；肘部轻微弯曲并全程固定、动作发生在肩关节；高位向下引偏下胸、低位向上引偏上胸；常见错误为重量过大与屈肘变推胸、用髋或上身借惯性。
- [Built With Science · STOP Doing Chest Flyes Like This](https://builtwithscience.com/fitness-tips/stop-doing-chest-flyes-like-this) — 访问 2026-09-10 — 支持：起始微屈肘、顶端逐渐伸直并夹拢双肘；钢索方向需与手臂方向一致；耸肩前引会把受力转向前束；重量过大会破坏动作。
