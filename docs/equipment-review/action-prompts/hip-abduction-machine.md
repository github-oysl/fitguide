### 1.2 建议修正或补充

1. 次要肌群改写为：「阔筋膜张肌与臀大肌（上部纤维）辅助，但坐姿外展中臀大肌参与有限」。
2. 器械设置补充：「腿垫贴在大腿外侧、膝关节上方，不要压在膝关节上；座椅高度使膝关节对准转轴」。
3. 常见错误补充：「上身后仰靠死靠背」「用甩动惯性把腿撞开」「只做半程」「重量过大导致骨盆旋转、腰背代偿」。
4. 提示语保留「外展是向外打开、内收是向内合拢」；前倾属常见变式，但本机不需为前倾/后仰单独建档，也不写「只练臀上部」这类无依据说法。
5. 模式切换须在安全卸力后按原机说明操作，本页不猜切换次序；本机以照片 43 铭牌 Inner/Outer Thigh 为类别依据。
