### 1.2 建议修正或补充

1. 本动作尚无现有文案，上表为建议入库的首版要点；与 `hip-abduction-machine` 必须分列，方向相反、目标肌群不同。
2. 步骤与提示必须写清「内收＝大腿向身体中线向内合拢」，避免与「外展＝向外打开」混淆。
3. 器械设置注明「双腿位于腿垫外侧」；起始幅度以髋部舒适为限，垫子相触即可，不让配重撞击。
4. 模式切换须在安全卸力后按原机说明操作，本页不猜切换次序；本机以照片 43 铭牌 Inner/Outer Thigh 为类别依据。
5. 不写「瘦大腿内侧」等局部减脂说法。
