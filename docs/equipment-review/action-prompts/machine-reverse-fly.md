### 1.2 建议修正或补充

1. 前置条件：E19 是否为「夹胸＋后束」双功能机未获铭牌证实；仅在模式切换或起始摆臂位置确认支持后束模式后，页面才提供本动作，否则保持「条件适用」。
2. 主要肌群写「三角肌后束」；次要肌群写「中斜方肌、菱形肌，上斜方肌与背阔肌可参与代偿，下斜方肌与肩袖参与稳定」。
3. 动作提示：反坐后先让肩胛自然前伸，用后束带动手臂向后水平打开，末端再轻夹肩胛；不要一开始就夹紧肩胛。
4. 座椅高度以手臂与地面接近平行为准，坐太高或太低都会改变力矩、降低后束发力。
5. 常见错误补充「肘部大幅弯曲把动作做成划船」「身体前后晃动借力」「重量过大，后束变成斜方肌代偿」。
6. 中立握（掌心相对）据来源对后束激活更高；本机握把是否支持中立握需现场核对。
