## 如何使用提示词

1. 打开某个动作 `.md`，复制「二、关键动作图提示词」或「三、常见错误图提示词」中的整段中文提示词。
2. 粘贴到 GPT Image 2.5（ChatGPT 生图 / 兼容网关）出图，尺寸选横构图 3:2。
3. 图上中文标注若有个别错字，用同一张图做局部重绘（保留画面、只改文字）。
4. 生成结果请与现场器械/原机说明核对后再用于教学；AI 图不能作为动作技术正确性的证据。
