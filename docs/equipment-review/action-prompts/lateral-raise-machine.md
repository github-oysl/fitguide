## 一、核对结论

### 1.1 逐项核对

| 核对项 | 现有内容（摘要） | 结论 | 说明 / 依据 |
|---|---|---|---|
| 主要肌群 | 三角肌中束 · 肩外侧 | ✅ 正确 | 来源以三角肌中束为主动肌，动作是肩外展 |
| 次要肌群 | 肩袖、斜方肌辅助 | ⚠️ 建议修正 | 来源还列三角肌前束早期参与、冈上肌、前锯肌与斜方肌上束稳定，建议补齐 |
| 器械设置 | 侧平举机＋上臂支撑垫；调座椅使支撑垫贴在肘附近的上臂外侧 | ❓ 待器械确认 | 本批未确认专用上臂垫式侧平举机（不等于现场没有）；方向与来源「肩关节与转轴对齐、上臂贴垫下」一致 |
| 动作步骤 | 握把坐稳、肩下沉、向两侧抬上臂至近肩高、慢慢收回 | ✅ 正确 | 与来源「肘微屈约 10–15°、抬到约与地面平行、受控回程」一致 |
| 常见错误 | 不要抬肩代替抬上臂；垫子压迫关节就重调座位 | ✅ 正确，可补充 | 来源另列重量过大、抬过肩高使斜方肌代偿、肘角改变、借惯性晃动 |
| 训练剂量 | 2–3 组 × 12–15 次 | ✅ 合理 | 来源建议中束以 12–15 次为主，重量宜轻 |

### 1.2 建议修正或补充

1. 次要肌群改为：「三角肌前束早期参与，冈上肌、前锯肌与斜方肌稳定辅助」。
2. 器械设置标注为「通用机型示意（本批未确认专用上臂垫式侧平举机，不等于现场没有）」。
3. 常见错误补充：「重量过大靠晃动甩起」「抬过肩高使斜方肌代偿」「抬起过程中肘角变化」「回程放任配重下坠」。
4. 座椅高度以「肩关节与器械转轴对齐、上臂贴在支撑垫下」为准；支撑垫压到关节时重新调整。
5. 抬升高度到约与地面平行即可；更高会更多动用斜方肌。
