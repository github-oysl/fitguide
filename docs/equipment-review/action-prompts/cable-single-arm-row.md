### 1.2 建议修正或补充

1. 前置条件：先确认 E03 有单手柄，且滑轮高度符合目标——偏低者更偏背阔肌、偏高者更偏上背／后束；否则本动作保持「条件适用」。
2. 主要肌群写「背阔肌、中下斜方肌、三角肌后束」；次要写「肱二头肌、前臂屈肌、肩袖，菱形肌参与」。
3. 设置与步伐：对侧脚在前的分腿站姿，膝盖微屈、核心收紧、躯干保持方正，不把钢索拉向胸口（否则肱二头肌代偿）。
4. 动作提示：用肘部向后向下把把手拉向髋部／下腹，末端让肩胛下沉后收；回程让手臂完全伸展，获得背阔肌拉伸。
5. 常见错误补充「耸肩把上斜方肌卷进来」「回程只放一半」「靠腰部前后摆动借力」。
6. 不与坐姿脚撑划船共用步骤：本动作是站姿单臂版本，不能用 `cable-row-seated-narrow-grip` 的坐姿教学代替。
