# 动作出图模板（内部规范 · 所有 action-prompts 文件遵循）

> 本文件是给内容维护者/AI 的格式规范，不是动作数据。每个动作一个 `<id>.md`，结构固定为四段。

## 文件命名
`docs/equipment-review/action-prompts/<动作ID>.md`

## 标题与头部字段
```markdown
# <中文名> · <ENGLISH NAME>

- 动作 ID：`<id>`
- 对应实拍器械：<E 编号 + 器械名，见 photo-audit/equipment-inventory.md>
- 适配状态：可直接教学 / 条件适用（需附件） / 待器械确认
- 核对日期：2026-09-10
- 现有数据：`data.js` / `extra-data.js` / `activity-data.js` / 建议新增
- 本文件内容：教学文案核对 + GPT Image 2.5 生图提示词（关键动作 / 常见错误）
```

## 正文三段（标题固定，不要新增空的「统一风格」段）
- `## 一、核对结论`
  - `### 1.1 逐项核对`：表格，列为 核对项 | 现有内容（摘要） | 结论 | 说明 / 依据。
    核对项至少覆盖：主要肌群、次要肌群、器械设置、动作步骤、常见错误、训练剂量。
    结论只用：`✅ 正确` / `⚠️ 建议修正` / `❓ 待器械确认`。
  - `### 1.2 建议修正或补充`：只列真正需要改的点，写清「现状 → 建议改成什么」。
  - `### 1.3 来源`：每条格式 `[标题](URL) — 访问 2026-09-10 — 支持：<具体断言>`。
    至少 2 条独立来源；不许写没打开过的链接，不许拿搜索摘要当依据。
- `## 二、关键动作图提示词`：一个 ```text 代码块，含 1 段可直接复制的提示词。
  必须写清：器械设置 → 身体位置 → 动作轨迹 → 3–4 个中文标注点（用「」给出确切文字）。
- `## 三、常见错误图提示词`：一个 ```text 代码块。
  只演示**一个**最典型错误；红色 `✗` + 2–3 条中文标注；角落给一句正确提示。

## 提示词统一风格（融进每段提示词，单独成段）
每条提示词都是**一段自包含中文文本**，固定包含以下风格要素（不另起 `【】` 块）：
写实健身教学照片 / 真实商业健身房 / 亚洲成年模特 / 深灰或墨绿运动服、无品牌 logo /
35mm 镜头、全身入镜、侧前方 45° / 自然顶光 / 横构图 3:2 / 写实皮肤与器械质感 /
叠加简体中文教学标注（白色描边、清晰可读、不遮挡身体）/ 红色引线箭头标关键点、绿色 `✓` 标正确、红色 `✗` 标错误 /
结尾禁用项：多余手指、扭曲关节、漂浮器械、乱码文字。

## 硬性约束
- 动作轨迹、肌群、器械方向必须与 `equipment-inventory.md` 的机型判断一致。
- 器械身份未确认的动作（E12、E15、E16、E17、E18、E21）：不绑定具体机型，也不假装图与现场机器一致。
  如需出图，只能产出「通用机型示意图」，并在头部字段写明「待现场核对（通用机型示意）」，
  且在两条提示词首句加「通用机型示意图，非现场机型，须现场核对」。若连动作姿势都未定（E12/E16/E18），则不出图，只写核对结论与缺失证据。
- 不写「完全隔离某块肌肉」「局部减脂」「膝盖绝不能过脚尖」等无依据绝对话。
- 不用 AI 生成图去证明动作技术正确性。
