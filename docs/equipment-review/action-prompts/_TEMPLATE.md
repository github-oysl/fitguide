# 动作出图模板（v2）

适用 [自动流程](../../image-generation-workflow.md)。复制为一个动作的 <action-id>.md，填写下列字段与代码块。完整实例见 [正握高位下拉](lat-pulldown-with-pronated-grip.md)。其他尚未声明 v2 的文件只作为迁移输入。

## 文件头

~~~markdown
# <中文动作名> · <英文名>

- 提示词版本：2
- 动作 ID：`<action-id>`
- 器械 ID：<E/B编号；无器械写 none>
- 工位 / 变式：<station-id> / <variant-id>
- 适配状态：<证据充分 / 条件适用 / blocked-evidence>
- 提示词状态：<已填写 / 待补证据>
- 图片状态：<未生成 / 首图校验中 / 整套校验中 / complete / partial / failed-limit>
- 现有数据：<源文件 / 建议新增>
- 资料核对日期：<实际日期>
~~~

## 一、核对结论

保留原动作已核对内容和来源，逐项覆盖主/辅肌群、器械设置、动作步骤、错误示例、训练剂量。修改技术结论时打开可靠来源并记下具体支持的断言与访问日期；不要伪造来源、把模型图当证据或把其他机型的说明书当本机说明书。

## 二、器械与空间约束

填写表格，不能仅写器械名称。

| 项 | 必填内容 |
|---|---|
| 主照片 | 仓库相对路径、编号、用于核对的结构 |
| 补充照片 | 路径、编号、补足什么；单图足够时写理由 |
| 不确定项 | 已核实 / 缺什么证据 / 是否影响动作与识别 |
| 外形不变量 | 框架、座/靠垫、颜色、压垫、导轨/转轴、配重/挂片等 |
| 人与器械关系 | 朝向、坐/站位置、身体支撑、手脚接触点 |
| 机械关系 | 力从负载经什么连接到手/脚，哪些部件移动 |
| 附件与模式 | 原装握把/钢索附件/模式，证据状态 |
| 相机 | 能看清朝向、关键关节与接触点的机位；所需运动留白 |
| 同组固定条件 | 亚洲成年男性、墨绿服装、同脸体型、服装、器械、光线背景和机位 |
| 复用范围 | 只对已证实同一实例/工位/配置复用空机图 |

自重、静态和有氧适配按通用流程处理。没有实拍时不能将下列器械占位符自动补成通用机器。

## 三、图片提示词

下列代码块是模板。实际调用时把 <公共约束全文> 和所有占位符展开为具体事实；每次调用只生成一个角色的一张图片。记录输入图片顺序，区分实拍、人物锚点与风格参考。

公共约束应包含：写实教学照片，1:1，全身与关键器械完整，四边目标 8% 留白，底部 12% 无关键接触点（可容纳窄口令条）；自然柔光与干净背景；器械照片约束、正确接触、固定人物和机位；无品牌 Logo、水印、畸形或拼图。图内仅出现本角色给定的短标签、箭头、定位文字和口令。

### force · 发力讲解（先生成）

```text
参考图1=<主实拍>，图2=<补充实拍>，图3=<可选风格参考及仅允许借鉴的内容>。<公共约束全文>。演示<动作名>的<明确发力阶段>：<朝向、坐/站位、手脚接触、关节、握法、移动部件位置>。<1–2条箭头的起点、轨迹、终点>；标注<准确接触/稳定提示>，不能遮挡关节。小标签“发力讲解”，口令“<一句话>”。只输出一张。
```

验收点：<原图对应结构、朝向、姿势、接触、箭头方向、逐字文字、构图>。
页面配文：<与图对应、可编辑的口令及更详细解释>。

### equipment · 单独器械

```text
参考<通过的force>保持器械与光照，参考<全部必要实拍>锁定真实结构。<器械相关公共约束全文>。移除人物，保持<工位配置>，运动部件处于<合理空机状态>；顶部、底座、座位、接触垫、轨迹与负载连接可辨。图片无文字、箭头、肌肉图。只输出一张空机1:1照片。
```

验收点：<身份、配置、完整性、无人、机械连接>。
无器械时：保留此角色说明 not-applicable，实际不调用。

### start · 正确起始

```text
参考<通过的force>与<必要实拍>。<公共约束全文>。保持同组固定条件，只改变至<起始姿势>，说明<关节、手脚、负载与器械状态>。和发力图的差异是<可观察差异>。小标签“起始姿势”，口令“<一句话>”。只输出一张。
```

验收点：<阶段差异、接触、人体、中文>。
页面配文：<口令和解释>。

### end · 正确结束

```text
参考<通过的force>与<必要实拍>。<公共约束全文>。保持同组固定条件，只改变至<结束姿势>，说明<终点关节、握法、身体接触、器械状态>，与发力中途差异为<可观察差异>。小标签“结束姿势”，口令“<一句话，含必要控制还原提示>”。只输出一张。
```

验收点：<终点与中途分开、不额外借力、关键手脚完整>。
页面配文：<口令和解释>。

### error-01 · <单一明显错误>

```text
参考<通过的force或对应正确阶段>与<必要实拍>。<公共约束全文>。仅演示这个错误：<明确姿势或器械设置错误>。把<相关身体部位>改成<明显可见偏差>，其余接触和设置保持正确，不叠加别的错误。红叉/红圈放在<具体位置>，标注“<错误名>”。小标签“错误示例”，口令“<纠正方式>”。只输出一张。
```

验收点：<实际姿势差异，缩略图不依赖红叉也可识别>。
页面配文：错误原因：<原因>；纠正方式：<方法>。
按需要复制为 error-02…，每个代码块只演示一种错误。

### muscles · 主要锻炼肌群

```text
独立1:1主要肌群讲解图，参考<通过的force>的体型与绿白风格。以<前/后/侧视角>展示<身体范围>，主肌<准确名称>以<高亮色>定位在<解剖边界>，其余低对比灰色。精简引线指向主肌；文字仅“主要锻炼肌群”“<肌肉名>”“<位置与作用>”。人物完整或采用明确合理的对称裁切，标签不挡主肌。无器械拼图、品牌 Logo、水印；不把辅助肌全当主肌，也不往动作示范照片上涂热力图。
```

验收点：<肌群定位、作用、引线、文字、人体完整性>。
页面配文：<主肌及有证据的辅助说明>。

## 四、校验与生成记录

提示词写好不等于图片完成。按通用流程记录每个 role 的 attempt、版本、锚点依赖、五项评分、硬性问题、实际输出与选定版本；初次0，最多修正1和2。首图必须通过才进入其余图片。图片状态与提示词状态分开维护。

## 五、缺项与下一步

记录证据阻塞、模板迁移、生成/复检、正式页接入的待办，链接工作计划的动作行。缺关键图片时不能标 complete。
