# 器械照片审核：一手资料与适用边界

核验日期：2026-09-09（用户时区）。本文件核验**器械类别、厂家明示功能及后续动作研究入口**。下面其他品牌的产品仅作结构参照，不能证明实拍器械就是该品牌或型号。具体照片归属以同目录的照片审核结果为准。

## 来源索引

以下 15 组资料均来自品牌自有网站或 ACE；除单独标注的补充检索线索外，已打开并阅读相关正文。厂家产品介绍能支持其机器的设计用途，不能单独支持“最佳增肌动作”“完全隔离某肌肉”等效果结论。

### S01：线性腿举

[Life Fitness — Plate Loaded Linear Leg Press](https://www.lifefitness.com/en-us/catalog/strength-training/plate-loaded/life-fitness-linear-leg-press)

- 已读结论：页面确认线性腿举这一产品类别，列出可调背垫与滑车释放机构。
- 支持：将背部支撑、脚踏板、滑车及挂片机构作为腿举的组合核验点。
- 不支持：照片的确切倾角、空车重量、最大承重或品牌型号。不能把本型号参数抄给其他器械。

### S02：哈克深蹲

[Hammer Strength — Plate-Loaded Linear Hack Squat](https://shop.lifefitness.com/products/hammer-strength-plate-loaded-hack-squat)

- 已读结论：厂家将其命名为 Hack Squat，说明深度限位、可调脚平台及本型号的 45° 设计。
- 支持：哈克深蹲是需单列的类别；倾斜导轨本身不足以把器械认定为腿举。
- 不支持：所有哈克均为 45°；所有斜轨机器均能腿举与哈克互换。照片识别应进一步观察肩垫、身体承托和实际运动部件。产品页的营销性肌肉效果描述未作为研究证据采用。

### S03：俯卧腿弯举

[Freemotion — EPIC Selectorized Prone Leg Curl](https://www.freemotionfitness.com/strength-machine/prone-leg-curl/)

- 已读结论：ES814 为俯卧腿弯举，厂家说明躯干和前臂支撑、可调腿部组件，并将目标描述为腘绳肌。
- 支持：俯卧身体支撑与小腿滚垫组合是类别核验线索；应使用 `prone leg curl` 或 `lying leg curl` 检索。
- 不支持：存在滚垫就一定是腿弯举；可调起始角度就能兼做腿屈伸。

### S04：坐姿腿弯举 / 腿屈伸双功能

[Life Fitness — Axiom Series Seated Leg Curl / Extension](https://www.lifefitness.com/en-us/catalog/strength-training/selectorized/axiom-series-seated-leg-curl-extension)

- 已读结论：厂家明确列出 3 个伸膝工作臂位置和 3 个坐姿腿弯举位置，以及背垫、胫部垫、大腿垫的调节。
- 支持：双功能机器真实存在；确认双功能需要工作臂模式及垫位证据，而不只是外形像坐姿腿弯举。
- 不支持：每台坐姿腿弯举都能伸膝；每台 Leg Curl / Extension 的弯举姿势都是坐姿。必须核对实际型号说明。
- 补充检索线索：[Cybex — Prestige Seated Leg Curl](https://locator.lifefitness.com/products/prestige/seated-leg-curl.aspx) 的搜索索引列出大腿固定垫和坐姿调节；本次直接打开返回 502，因此不作为独立完成核验的页面。它提醒审核时单独考虑“仅坐姿腿弯举”的候选。

### S05：夹胸 / 反向飞鸟双功能

[Life Fitness — Insignia Series Pectoral Fly/Rear Deltoid](https://shop.lifefitness.com/products/insignia-series-pectoral-fly-rear-deltoid)

- 已读结论：厂家明确命名为胸部飞鸟 / 后束双功能，并称为 two-in-one。
- 支持：在铭牌或调节机构确认后，同一器械对应夹胸、反向飞鸟两个动作。
- 不支持：所有蝴蝶机都能反坐使用；所有机型的夹胸都用竖握把、后束都用横握把。握把和工作臂调整必须以现场说明为准。

### S06：髋内收 / 外展双功能

[Life Fitness — Insignia Series Hip Abduction / Adduction](https://www.lifefitness.com/en-gb/catalog/strength-training/selectorized/insignia-series-hip-abductor-adductor)

- 已读结论：厂家明确说明换向机构使两个方向都能提供阻力，并标注为双功能。
- 支持：真正的内外展双功能需要换向功能；动作名称应区分向外打开的髋外展、向内合拢的髋内收。
- 不支持：仅能翻转腿垫就已证明双功能；把单方向负重动作的回程当成另一个独立负重动作。

### S07：辅助引体 / 双杠臂屈伸的重量方向

[Dynasty Fitness — Assisted Chin/Dip DRE8008](https://www.thedynastyfitness.com/products/assisted-chin-dip-dre8008)

- 已读结论：厂家明确表示，配重选择越大，承托平台提供的辅助越多，使用者需抬起的有效体重越少。
- 支持：配重反向辅助型器械应记录 `assistance`；不能按普通负重器械解释“数值越大难度越高”。
- 不支持：任何机器显示的辅助重量都与实际卸载体重精确相等；不能忽略滑轮比例和机构差异直接计算。也不证明照片是这个型号或采用站立平台。

### S08：无胸垫 T 杠划船

[Hammer Strength — Plate-Loaded T-Bar Row](https://www.lifefitness.com/en-us/catalog/strength-training/plate-loaded/hammer-strength-plate-loaded-t-bar-row)

- 已读结论：厂家明确描述无身体支撑的站姿、髋铰链和躯干稳定要求，并将其与胸垫划船区分。
- 支持：无胸垫 T 杠划船不应与胸托型合并为同一器械条目；动作研究要匹配支撑条件。
- 不支持：照片中所有 T 形杆都是地雷管附件；本产品不同挂片位置的设计也不能推定现场存在。

### S09：胸部支撑的杠杆 / 地雷管划船

[Rogue — Monster Pritchett Pad](https://www.roguefitness.com/gb/rogue-monster-pritchett-pad-eu)

- 已读结论：厂家说明该胸垫用于胸部支撑划船，正文明确讨论胸托式地雷管划船。
- 支持：胸垫是应记录的支撑条件；胸托与无胸托动作需要分别研究。
- 不支持：照片中的胸托 T 杠划船就是 Rogue 附件；该来源不是对任何整机 T 杠划船结构的全面说明。专用斜板杠杆划船另见 S12 中的 Incline Lever Row。

### S10：挂片高位划船

[Life Fitness — Plate Loaded High Row](https://www.lifefitness.com/en-eu/catalog/strength-training/plate-loaded/life-fitness-high-row)

- 已读结论：厂家命名为 High Row，描述独立、向下拉动的轨迹。
- 支持：高位划船也可以从高处向下拉；仅见高把手与向下拉动，不足以认定高位下拉。
- 不支持：以挂片位置、把手高度或有无胸垫单一特征区分所有高位下拉与高位划船。需合并检查身体朝向、把手轨迹、支撑结构和铭牌。

### S11：挂片高位下拉

[Hammer Strength — Iso-Lateral Front Lat Pulldown](https://www.lifefitness.com/en-us/catalog/strength-training/plate-loaded/plate-loaded-iso-lateral-front-lat-pulldown)

- 已读结论：厂家将其命名为前侧高位下拉；这个型号采用独立工作臂与反握设计。
- 支持：高位下拉不一定是钢索拉杆结构；挂片杠杆机器也可以是高位下拉。
- 不支持：所有挂片下拉都适合反握；不能仅因把手相似而确认品牌型号。与 S10 合用时，应保留照片证据不足的候选，而不是强行统一名称。

### S12：肩推与上斜胸推；斜板胸托划船

[Precor — Discovery Plate Loaded 全系列](https://www.precor.com/en-US/strength/plate-loaded/discovery/all)

## 将来源用于照片识别时的规则

1. **先看实物证据，再找结构一致的来源。** 来源证明的是某种设计存在，不是用户恰好拍到了这个型号。
2. 双功能须有两种负重模式、工作臂调整或铭牌依据；不能因为动作回程方向相反就认定双功能。
3. 以器械结构去重，不以训练肌群去重。高位划船、下拉、胸托 T 杠划船、无胸托 T 杠划船可以共同练背，但不能因此合并。
4. 产品销售页中的“最佳”“自然”“减少关节压力”“最大激活”等宣传不能自动升级为普遍训练结论。若要入库这类结论，应另查直接相关研究并写清适用人群和限制。
5. 未读到的说明书、打不开的页面、仅视频标题均不得写成已经完成动作技术校验。

## 绳索动作后续研究的建议查询组

以下是研究候选，不代表已核实现场配件齐全：

| 候选动作 | 英文查询词 | 核对的现场条件 |
|---|---|---|
| 三头肌下压 | cable triceps pressdown / pushdown | 高滑轮、适用直杆或绳把 |
| 绳索弯举 | cable biceps curl | 低滑轮、短杆或单手柄 |
| 绳索夹胸 | standing cable fly / crossover | 两侧滑轮、两个手柄、站位空间 |
| 绳索划船 | seated cable row / standing cable row | 滑轮高度；坐姿版本另需合法稳定的脚撑/座位 |
| 直臂下拉 | straight-arm cable pulldown | 高滑轮、适用拉杆、完整钢索行程 |
| 面拉 | cable face pull | 合适高度、绳把和足够行程 |
| 绳索侧平举 | single-arm cable lateral raise | 低滑轮、单手柄 |
| 抗旋转推 | standing anti-rotation press / Pallof press | 躯干高度滑轮、侧向站位空间 |
| 臀后踢 / 髋外展 / 内收 | cable hip extension / abduction / adduction | 低滑轮、正式踝带、可扶持结构 |

每项研究需匹配滑轮高度、单双侧、附件和身体支撑；再从具体动作页提取起始设置、主要关节动作、执行步骤和常见错误。若现场条件未确认，器械—动作关系应标为“条件适用”，并明确缺少哪项证据。
