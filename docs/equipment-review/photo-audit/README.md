## 结论的边界

本轮逐张查看了全部照片的联系表，并对铭牌、结构和易混淆项查看原图或局部。照片身份是实拍判断，网页来源用于核查通用器械原理；其他品牌的产品页不能证明本场地机器的具体型号。

**器械名称识别、动作适配、动作教学审核是三个不同状态。** 表中“高”仅表示类别识别证据较强，不等于已经获得该机型说明书，或可以不经审核发布完整教学。不能从静态照片确认的运动方向、换向方法、安全锁和配重倍率均保留待核验。

共建立 **26 个主要器械／工位归档条目**（包含同一张图中的楼梯机与训练凳分别建档），另记背景中的哑铃、训练凳、杠铃架和跑步机。这是知识库归档数，**不是健身房机器台数**，其中含暂定类别。

文件 SHA-256 比对结果：36 个文件的哈希均不同，**没有字节完全重复文件**。去重采用知识归档合并：同机多角度、铭牌近照保留为证据；同类不同实例、组合架不同工位保持区别。没有删除、移动或改名原照片。
